# Datathon project description

**Solution:** Renatura Normandie

**Keywords:** restoration, biodiversity, hedgerows, connectivity, explainability,
local-first, integer optimisation, sensitivity, open data.

**Problem:** Help regional and local stakeholders compare restoration priorities
and resource-constrained sets of planning units with transparent assumptions.

**Targets:** Local authorities, conservation practitioners, regional decision-makers
and residents who want to understand the evidence behind priorities.

**Delivered scope:** Static tablet-ready pilot on FR2502014, an offline Python
pipeline, five model-optimal scenarios and reproducible sensitivity results.

**Expected benefits:** More transparent trade-off discussion, source traceability,
explicit data-gap reporting and low infrastructure requirements. These benefits
have not yet been measured in a user study or ecological evaluation.

**Sources:** DREAL Normandie historical hedgerows and woodland, DREAL Natura 2000
boundary, public administrative commune API. Full links and attribution are in
`dist/data/data_catalog.json`.

**Team:** Project owner to complete.

**Solution link:** Use the deployed link supplied with the delivery.

**Screenshots:** Not supplied; capture from the deployed application after device QA.

**Limitations:** Historical partial pilot; no full-region assessment, real cost
model, pressure/feasibility layer, field calibration or expert validation.
